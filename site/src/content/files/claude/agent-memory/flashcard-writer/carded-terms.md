Terms carded per module, so a future module's flashcard-writer can skip terms already covered and spend its twelve slots on new material.

**Why:** Debrief instructions say a term carded before does not need a second card. This log is the only place that history lives, since flashcards.md files are per-module and don't cross-reference each other.

**How to apply:** Before choosing terms for a new module, read this list. If a candidate term is already here, drop it and pick something new instead, unless the module gives it materially new treatment worth a fresh card.
